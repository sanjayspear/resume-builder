# Fonts

These fonts are embedded in the PDFs the app creates. All of them are licensed
under the **SIL Open Font License 1.1**: the copyright notices and the full
licence text are in [OFL.txt](OFL.txt).

| Font | Project | Used for |
| --- | --- | --- |
| Source Sans 3 | Adobe ([adobe-fonts/source-sans](https://github.com/adobe-fonts/source-sans)); Reserved Font Name "Source" | Classic Sidebar (default font) |
| Inter | [rsms/inter](https://github.com/rsms/inter) | Classic Sidebar option; Modern ATS body text |
| Roboto | [googlefonts/roboto-classic](https://github.com/googlefonts/roboto-classic) | Classic Sidebar option |
| Gelasio | [SorkinType/Gelasio](https://github.com/SorkinType/Gelasio) | Classic Sidebar option (Georgia look-alike) |
| Carlito | [googlefonts/carlito](https://github.com/googlefonts/carlito) | Classic Sidebar option (Calibri look-alike) |
| Montserrat | [JulietaUla/Montserrat](https://github.com/JulietaUla/Montserrat) | Modern ATS name and headings |

The files are the Latin-character web versions (WOFF) as distributed for the
web; this project doesn't change them. Files are named
`<Family>-<weight>-<style>.woff`.
